## Дальше

### 5. Встречи вместо походов
- Миграция `004`: удалить `trips` (реальных данных нет), создать две таблицы.
  - `meetups`: `place_id`, `title`, `description`, `starts_at`, `capacity` (`NULL` — без лимита), `visibility` `public|friends`, `invite_token`, `status`.
  - `participants`: `status` `confirmed|waitlist|offered`, позиция в очереди, `offer_expires_at`.
- Пакет `internal/trips` → `internal/meetups`. Сохраняем образцы: `Input.Validate`, `SetStatus` с `ErrStaleStatus`, `Filter`.
- Создать встречу можно со страницы места и из попапа на карте.
- **Открытая встреча** видна на карте (у места бейдж «2 встречи») и в списке.
- **Встреча «для друзей»** доступна только по ссылке `/m/{token}`. Чужой или неверный токен — 404, в API карты такая встреча не попадает.
- **Запись** — в транзакции с `SELECT … FOR UPDATE` по встрече:
  - есть свободные места — `confirmed`, иначе — в лист ожидания;
  - при отмене место предлагается первому из очереди: `offered`, 24 часа на подтверждение;
  - фоновый воркер снимает просроченные предложения и предлагает место следующему.
- Профиль: «Мои встречи» и «Я участвую».
- Ключевой тест: 50 горутин записываются на 10 мест → ровно 10 `confirmed` и 40 в очереди, позиции без дыр. Плюс отмена и продвижение очереди, а также истечение предложения (часы подменяются).

### 6. Предложить место
- Форма «Предложить место»: точка на карте, группа и вид, название, описание. Место сохраняется со статусом `draft` и автором.
- Страница модерации `/admin/places` для роли `admin`: опубликовать, поправить, отклонить.
- Ограничение частоты, чтобы один пользователь не засыпал модерацию.

### 7. Чат встречи
- Таблица `messages` (`meetup_id`, `user_id`, `text`, `created_at`).
- Отправка через POST формы или fetch, получение через SSE (`/m/{id}/stream`).
- Читать и писать могут только участники (`confirmed`, `offered`); остальным 403 и на отправку, и на поток.
- Лимит: 1 сообщение в секунду и до 1000 символов. При открытии чата подгружается история.

### 8. Полировка для портфолио
- README со скриншотами и схемой архитектуры, демо-данные (встречи на ближайшие выходные).
- GitHub Actions: `gofmt`, `go vet`, `go test` с сервисом Postgres.
- Деплой: VPS или Fly.io, HTTPS, `SECURE_COOKIES=1`.
