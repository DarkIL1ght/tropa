## Технический долг
- `/u/{id}` открыта гостям, id идут подряд: имена пользователей можно перебрать. Для пет-проекта приемлемо (email не показывается); если станет важно — случайный публичный id или страница только для вошедших.
- Счётчики попыток (`internal/web/limit.go`) живут в памяти: при рестарте обнуляются, при нескольких экземплярах сервера не общие. Для одного VPS достаточно.
- Сообщения боту принимает long polling: сервер с одним токеном можно запускать только в одном экземпляре. Для нескольких — вебхук.
- Ссылка «Открыть в 2ГИС» строится поиском по названию рядом с точкой. Для мест с общими названиями она может открыть не то — проверить на нескольких местах.

## Правила (кратко, полные — в `CLAUDE.md`)
- Данные 2ГИС не брать (лицензия запрещает хранение), только ссылкой. Места — из OSM и вручную, подпись «© участники OpenStreetMap».
- Координаты не писать по памяти: только по OSM, с `osm_ref`.
- Коммиты без Co-Authored-By. Перед коммитом: `gofmt -l .`, `go vet ./...`, `go test ./...` с `TROPA_TEST_DATABASE_URL`.
