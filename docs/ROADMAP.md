### 6. Уведомления в Telegram
Без них лист ожидания работает вполсилы: место освободилось, а человек об этом не знает и через сутки теряет его.
- Свой бот сайта (не бот для разработки), токен — `TELEGRAM_BOT_TOKEN`. Без токена уведомления выключены, сайт работает как раньше.
- Привязка аккаунта: в профиле «Подключить Telegram» → одноразовая ссылка `t.me/<бот>?start=<код>`. В базе — только хэш кода, срок 15 минут. Бот получает `/start <код>` и сохраняет `chat_id` у пользователя. Отвязать можно в профиле или командой `/stop`.
- Получение апдейтов — long polling `getUpdates` (локально и на VPS без публичного адреса); вебхук — по желанию при деплое.
- **Outbox**: таблица `notifications` (`user_id`, вид, текст, `created_at`, `sent_at`, попытки, `next_attempt_at`, последняя ошибка). Запись — в той же транзакции, что и событие (например, `fillSeats`), поэтому уведомление не теряется при падении.
- Воркер отправляет по очереди: повторы с растущей паузой на 429/5xx (учитывать `retry_after`), бот заблокирован (403) — отвязать `chat_id`, после N неудач — бросить.
- События:
  - освободилось место — с дедлайном и ссылкой на встречу;
  - до конца предложения осталось 2 часа, а ответа нет;
  - встречу отменили или перенесли (участникам и очереди);
  - напоминание за день до встречи (`confirmed`).
- Тесты: фейковый Telegram API на `httptest`; событие и запись в outbox в одной транзакции; повторы и 403; привязка по просроченному и чужому коду не работает.

### 7. Профиль
- Правка имени; смена пароля с текущим паролем, после смены остальные сессии закрываются.
- Публичная страница `/u/{id}`: имя, «с нами с», сколько встреч собрал и на скольких был, его предстоящие открытые встречи. Встречи «для друзей» там не видны никогда.
- Участники на странице встречи — ссылками на профили.
- В профиле — статус Telegram (подключён / подключить / отключить) из этапа 6.

### 8. Дизайн
Отдельным проходом по всем страницам, когда их набор устоялся.
- В помощь — плагин frontend-design для Claude Code; на сайте — свой `app.css` без CSS-фреймворков (без JS-сборки, всё встроено в бинарник, CSP без CDN).
- Страницы: карта и шторка на телефоне, место, встреча, список встреч, профиль, формы, вход и регистрация, 404.
- Пустые состояния, иконки инлайн-SVG, фавикон, единые карточки и кнопки, тёмная тема.
- Доступность: контраст, фокус, подписи полей. Скриншоты при 1280 и 492 px.

### 9. README, CI и деплой
- README со скриншотами и схемой архитектуры, демо-данные (встречи на ближайшие выходные).
- GitHub Actions: `gofmt`, `go vet`, `go test` с сервисом Postgres.
- Деплой: VPS или Fly.io, HTTPS, `SECURE_COOKIES=1`, бот уведомлений на том же сервере.

## Правила (кратко, полные — в `CLAUDE.md`)
- Данные 2ГИС не брать (лицензия запрещает хранение), только ссылкой. Места — из OSM и вручную, подпись «© участники OpenStreetMap».
- Координаты не писать по памяти: только по OSM, с `osm_ref`.
- Коммиты без Co-Authored-By. Перед коммитом: `gofmt -l .`, `go vet ./...`, `go test ./...` с `TROPA_TEST_DATABASE_URL`.
