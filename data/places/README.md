# Места

| Файл | Что в нём |
|---|---|
| `almaty.json`, `region.json` | Стартовые места (этап 1) и добавленные вручную (Арбат, Старая площадь, Кимасарское ущелье), координаты сверены с OSM. |
| `osm-wave1.json` | Первая волна из OpenStreetMap (этап 3), после разбора Дарханом — 135 мест. |
| `hidden.json` | Убранные из первой волны (status `hidden`): на карте их нет, а `osm-fetch` не вернёт их в кандидаты — их osm_ref уже «занят». |
| `indoor-drafts.json` | Антикафе, настолки и квесты из списка Дархана (status `draft`, не видны). В OSM этих заведений нет, точка — здание по адресу. Опубликовать (`published`) после проверки, что место работает по этому адресу. |
| `candidates.json` | Неразобранные кандидаты из `tropa osm-fetch` (status `draft`). `seed` этот файл **пропускает**. |

Загрузка в базу: `go run ./cmd/tropa seed`. Новые кандидаты: `go run ./cmd/tropa osm-fetch` (запрос к Overpass, 3–4 минуты; `--from <файл>` — пересобрать из сохранённого ответа). Принятые места из кандидатов исключаются автоматически по `osm_ref`.

## Как отбиралась первая волна

- **Граница** — настоящие полигоны Алматы и Алматинской области из OSM (`internal/places/boundary.json`), а не прямоугольник: иначе на карту попадали Бишкек, Каракол и Жетысуская область.
- **Взяты:** боулинги, скалодромы, картинги, крытый каток, Ой-Карагай; кино, караоке, квесты; крупные ТРЦ (16); музеи и театры Алматы, галереи; Тамгалы и музей-заповедник «Есик»; крупные парки; смотровые, водопады; популярные у походников вершины над городом до ~3300 м; ущелья Иле-Алатау над городом, Тургень, Аксай, Кайрак; Кольсайские озёра (все три), Аксайские, Сайран, Солдатское, Жасылколь, Бартогай.
- **Не взяты:** дубли уже принятых мест (Кок-Тобе, Ботсад, Чарын), «Вид на город» ×3 и прочие безымянные смотровые, сельские «Дома культуры», технические водоёмы, сложные вершины выше 3300 м, мелкие ТЦ и павильоны, огромные заповедники целиком.
- Длинные официальные названия сокращены, кавычки — «ёлочки», slug — короткий латиницей.
- Описаний у мест из OSM пока нет — их стоит дописать для самых популярных (15 дописаны 2026-10-28).
- **Разбор Дарханом (2026-10-28):** скрыты дикие и малоинтересные ущелья (Елик-Сай, Калдыбексай, Котырбулак, Мокрый ключ, Ортасай, Шукыр), Солдатское озеро, Flow Park и Археологический парк, 13 вершин, требующих подготовки, промежуточные ориентиры на тропах (Первый и Третий пуп, Слониха, Тыныштау), Әуежай Мұражайы и Музей мороженого. Убранное место — перенести в `hidden.json` со `status: hidden`, а не удалять: иначе в базе оно останется опубликованным.
